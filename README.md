# 프롬프트 통계

Marinara의 **프롬프트 구성** 창에서 요청의 원문과 토큰 통계를 확인하는 브라우저 확장입니다. 프롬프트를 프리셋, 사용자 지침, 캐릭터, 페르소나, 로어북, 기억, 최근 대화, 기타로 나누어 보여 줍니다.

**확장 v1.0.2** · Marinara Engine v2.5.2에서 제작

## 설치 전 설정

1. Marinara가 실행되는 컴퓨터의 `.env` 파일에 `ENABLE_EXTERNAL_EXTENSIONS=true`를 설정하고 Marinara를 다시 시작하세요. 서버를 다른 사람이 관리한다면 관리자에게 요청하세요.
2. Marinara에서 **설정 → 고급(Advanced) → 위험 구역(Danger Zone)**을 열고 경고를 읽은 뒤 **타사 확장 가져오기 허용(Allow third-party extension imports)**을 켜세요.
3. **설정 → Addons → External Extensions**가 표시되는지 확인하세요. [Marinara 외부 확장 설정 안내](https://github.com/Pasta-Devs/Marinara-Engine/blob/v2.5.2/docs/extending/personal-extensions.md#allow-third-party-imports)

## GitHub 확장 관리자로 설치

1. GitHub 확장 관리자에서 **확장 추가**를 누르세요.
2. 저장소 주소 `https://github.com/you2-use/Marinara-Prompt-Statistics`를 입력하고 **패키지 찾기**를 누르세요.
3. **manifest.json**을 선택하고 패키지 내용을 확인한 뒤 설치하세요.
4. **외부 확장(External Extensions)**에서 **프롬프트 통계**의 코드와 **전체 페이지 접근(Full page access)** 권한을 검토한 뒤 **검토 및 실행(Review and Run)**을 누르세요.

공개 저장소에서 설치하므로 GitHub 로그인이나 토큰 없이 받을 수 있습니다.

## ZIP으로 직접 설치

1. [v1.0.2 설치용 ZIP 다운로드](https://github.com/you2-use/Marinara-Prompt-Statistics/releases/download/v1.0.2/Prompt-Statistics.personal-extension.zip)

2. **설정 → Addons → External Extensions → 확장 파일 가져오기(Import Extension File)**에서 다운로드한 ZIP을 선택하세요. 압축을 풀 필요 없이 ZIP 그대로 가져옵니다.
3. 확장의 코드와 **전체 페이지 접근** 권한을 검토한 뒤 **검토 및 실행(Review and Run)**을 누르세요.

## 사용 방법

1. 채팅에서 마지막 AI 답변의 메시지 동작에 있는 **돋보기(Peek prompt)**를 누르세요. 이미 열린 프롬프트 구성 창이 있다면 닫고 다시 여세요.
2. 창 위쪽의 **통계**에서 분류별 토큰 추정치와 비율을 확인하세요. 그래프를 누르면 팔레트를 바꿀 수 있습니다. 제공자가 보고한 입력 토큰 수가 있으면 위에 따로 표시됩니다.
3. 분류와 항목을 펼치면 분류 근거와 해당 원문을 볼 수 있습니다. **원문** 탭에서 전체 프롬프트를 검색하고, **기본** 탭에서 Marinara 기본 화면으로 돌아갈 수 있습니다.
4. 항목 옆 **분류 변경** 버튼을 누르거나, 여러 항목에 체크한 뒤 목록 아래 **선택 항목 일괄 분류**를 누르세요. 구간의 일부만 옮기려면 가위 아이콘 **구간 나누기**를 누르고 텍스트를 선택한 뒤 분류를 골라 **선택 구간 적용**을 누르세요.

## 적용과 저장

- **이번 스냅샷**에 적용한 분류와 나눈 구간은 현재 창에만 남습니다. 목록 하단의 **마지막 임시 변경 취소**로 최근 50회까지 되돌릴 수 있습니다.
- 분류를 **이 채팅의 같은 경로·이름** 또는 **전체 채팅의 같은 경로·이름**에 적용하면 확장에 규칙이 저장됩니다. 같은 적용 범위와 항목의 기존 규칙은 새 분류로 바뀝니다. 같은 경로·이름을 쓰는 다른 프리셋에도 규칙이 적용될 수 있습니다. **설정** 탭에서 저장한 규칙을 삭제할 수 있습니다.
- 그래프 팔레트도 확장에 저장됩니다. 분류 변경과 분할은 통계 표시만 바꾸며, 채팅·프롬프트·프리셋 원본은 그대로 유지됩니다.
- 통계와 원문은 창을 처음 열었을 때의 내용을 표시합니다. 기본 탭의 현재 문맥이나 결정 테스트에서 다른 결과를 확인한 경우, 새 통계를 보려면 창을 닫았다 다시 여세요.

## 지원 범위와 권한

- Marinara의 프롬프트 구성 창이 제공하는 텍스트를 분석합니다. 태그와 제목으로 분류하며, 역할극에서 분류가 모호하면 현재 연결된 캐릭터·페르소나·로어북·대화·프리셋 원문을 대조합니다. 중복이나 불일치가 있는 구간은 수동으로 분류할 수 있습니다.
- 자동 대조는 최대 8초, 응답당 8 MiB, 자료 응답 전체 24 MiB까지 진행합니다. 연결 캐릭터는 12개, 로어북은 32개와 항목 2,000개, 대화는 최대 1,000개 메시지까지 확인합니다. 최신 요청은 최근 250개 메시지를 확인합니다.
- 제공자 보고값이 없거나 여러 요청의 누적값만 있으면 제공자 토큰 수가 표시되지 않을 수 있습니다. 분류별 숫자는 텍스트를 바탕으로 한 추정치입니다. 과거 요청의 자료가 이후 수정되거나 삭제된 경우, 현재 자료로 대조할 수 있는 부분만 분류합니다.
- 설치 형식은 GitHub 저장소의 `manifest.json` 또는 위의 `.personal-extension.zip`입니다.
- **전체 페이지 접근** 권한으로 Marinara 페이지에서 실행되어 프롬프트 구성 창과 그 응답을 읽습니다. 원문 대조용 자료는 현재 Marinara 서버에서 읽기 요청으로 가져옵니다. 프롬프트와 자료 본문은 메모리에서 처리하며, 외부 분석 서버로 전송하거나 모델을 호출하지 않습니다. 확장 저장소에는 분류 규칙과 팔레트가 저장됩니다.

## 업데이트

GitHub 확장 관리자에서 설치한 항목의 업데이트를 확인하세요. 관리자는 저장소의 기본 브랜치를 확인하며, JS·CSS 또는 권한이 바뀌었을 때 코드 업데이트를 표시합니다. 업데이트하면 기존 설정과 저장 규칙이 유지되고 확장은 꺼집니다. 새 코드와 권한을 검토하고 **검토 및 실행**으로 다시 승인하세요.

이름이 **Prompt Statistics**인 이전 시험판은 먼저 끄세요. 이름이 다른 항목으로 새로 설치하면 저장 규칙이 자동으로 옮겨지지 않을 수 있습니다.

## 문제가 생기면

- **외부 확장 메뉴가 없어요.** `.env` 설정과 서버 재시작, 위험 구역의 가져오기 허용을 확인하세요. 원격 접속 중이라면 **설정 → 고급 → 관리자 접근(Admin Access)**에서 관리자 설정이 필요한지 확인하세요.
- **GitHub에서 패키지를 가져오지 못해요.** 공개 저장소 주소를 입력하고 **manifest.json**을 선택하세요. 계속 실패하면 위의 설치용 ZIP을 받아 직접 가져오세요.
- **통계 탭이 안 보여요.** 확장이 실행 승인 상태인지 확인하고 프롬프트 구성 창을 닫았다 다시 여세요. 이전 확장 화면이 남아 있으면 이전 버전을 끄고 페이지를 새로고침하세요.
- **자료가 기타로 남아요.** 현재 연결 자료와 맞는 부분만 자동으로 분류됩니다. **설정**에서 기존 규칙을 확인하고 필요하면 **분류 변경**이나 **구간 나누기**를 사용하세요.
